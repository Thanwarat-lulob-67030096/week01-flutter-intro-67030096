# week01-flutter-intro-67030096

ใบงานการทดลองที่ 1 — วิชา Mobile Software Development
Flutter + Dart + Google AI Studio (Gemini API)

## สิ่งที่อยู่ในโปรเจกต์
- **Profile Card** (`lib/main.dart`)
- **Gemini AI Chat** (`lib/pages/ai_chat_page.dart`)

## วิธีรัน
```bash
flutter pub get
flutter run -d chrome     # หรือ flutter run สำหรับอุปกรณ์ Android
```

## ตั้งค่า API Key
แก้ `lib/config/api_config.dart` แล้วใส่ Gemini API Key ของคุณ
(สร้างได้ที่ https://aistudio.google.com) — **ห้าม commit key จริง**
